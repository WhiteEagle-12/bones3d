# bones3d

3D "name the highlighted structure" bone quizzes for BIO 264 lab review.

Models: [Z-Anatomy](https://www.z-anatomy.com), built on BodyParts3D © The Database Center for Life Science (DBCLS). Licensed CC BY-SA 4.0 (Z-Anatomy) and CC BY-SA 2.1 JP (BodyParts3D). The mesh files here (`*.bin.gz`) are converted from those models and share the same license.

`trackball.js` is three.js TrackballControls (MIT), with its import path changed.
